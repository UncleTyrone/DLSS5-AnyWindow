# DLSS5 AnyWindow 1.6.0 Wood UI and Editable Hotkey

此版本保留原有圆角布局与系统字体，只将控制器配色调整为木棕色、羊皮纸色和暖金色。处理引擎不再使用模糊的“稳定”命名，界面直接显示：

- `DLSS5 / DLSSNR`：NVIDIA NGX Feature 18 / DLSSNR 同尺寸实验处理。
- `CAS SHARPEN`：AMD FidelityFX CAS 单帧锐化，不使用 DLSS、历史帧、运动或深度。

## 可调全局快捷键

- 默认快捷键为 `Ctrl+Alt+F10`。
- 在设置中点击“开关快捷键”，然后按下新的组合键即可保存并立即注册。
- `Esc` 取消录入；`Backspace` 或 `Delete` 停用全局快捷键。
- 空闲时按快捷键开始 3 秒目标窗口选择；选择中按快捷键取消；渲染中按快捷键关闭滤镜。
- 控制器启动的渲染进程不再重复注册固定的 `Ctrl+Alt+F10`，避免与用户自定义快捷键冲突；渲染器独立启动时仍保留该紧急关闭快捷键。

## 继承的多显卡运行库选择

- RTX 20/30 自动选择 SF-v2 FP16 社区修改运行库。
- RTX 40 自动选择 RTX40 社区修改运行库。
- RTX 50 自动选择原始泄露运行库。
- 运行库来源与限制仍与 1.5.0 相同，均不代表 NVIDIA 正式公开的 DLSS 5 产品支持。

## 验证

- Release x64 控制器和渲染器编译通过。
- 125% DPI 下完整设置面板无裁切。
- 自定义快捷键 `Ctrl+Shift+F9` 注册成功；第二个进程无法抢占同一快捷键；退出后快捷键正常释放。
